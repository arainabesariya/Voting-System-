# LTCE Student Voting System

A small educational mini-project using HTML, CSS, JavaScript and browser localStorage.

## Run
1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Open `index.html` in a browser.
3. Use a sample ID from `LTCE001` to `LTCE025`.
4. Choose one candidate for President, Vice President, and Secretary, then submit.
5. Open the Analysis tab to see totals and percentages.

The student register screen has intentionally been removed. Candidate names and the 25 sample IDs are defined in `script.js`.

## Important
This is a local demo, not a secure real election system. Votes are saved in one browser only and are not shared across devices. Do not use real credentials or real election data.
